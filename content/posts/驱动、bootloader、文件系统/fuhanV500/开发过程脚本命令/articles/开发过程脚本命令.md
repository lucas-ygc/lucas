# uboot  emmc版本

## ip地址
```shell
setenv ipaddr '192.168.8.210';setenv serverip '192.168.8.217';
```

## 下载烧写uboot
```shell
mmc dev 0 1;tftp a1000000 Flash.img;mmc erase 0  2000; mmc write a1000000 0 2000
```

## 下载烧写内核
```shell
mmc dev 0 ; tftp a1000000 uImage_FH8856V500; mmc write a1000000 0 5500;reset
```

## 启动内核
```shell
mmc dev 0; mmc read 0xA1000000 0 5500; bootm 0xA1000000
```

## 分区
```shell
0-2M bootloader
2M-26M kernel
6001-M rootfs
