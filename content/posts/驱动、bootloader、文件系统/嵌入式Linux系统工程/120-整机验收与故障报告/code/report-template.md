# 板端实验与故障报告模板

## 身份与条件

- 硬件型号/修订/编号：待填
- 内核、设备树、根文件系统、SDK、模型、配置校验：待填
- 工具链及工具版本：待填
- 输入、负载、温度、供电、运行时长：待填
- 权限、内核配置与缺失功能：待填

## 实验协议

- 目标与可证伪假设：待填
- 操作步骤及只读/状态变更分类：待填
- 预期结果、通过阈值、停止条件：待填
- 恢复与回退方法：待填
- 观测开销与时钟域：待填

## 证据与结论

| 项目 | 预期 | 实际 | 原始证据 | 状态 |
|---|---|---|---|---|
| 功能闭环 | 待定 | 未测 | 无 | 未执行 |
| 吞吐/尾延迟 | 待定 | 未测 | 无 | 未执行 |

状态只使用：已验证、条件有限、未执行、失败。假设、观察值和最终结论分开记录。

## 修复与回归

记录现象、影响、首次出现版本、最小复现、排除过程、根因证据、修复行为及回归范围。重启恢复不等于根因已修复。未完成的长期验证继续保留为未执行。
