# 内存泄漏、越界与峰值

主机 20 轮有界对象分配与释放，验证活跃计数；不以 RSS 是否下降判定释放。

需要 Linux、C11 编译器和 libc 开发文件。第 100 课还需要工具链 ASan/UBSan 运行库。

```sh
sh run.sh
```

脚本在新建临时目录编译并运行，退出时清理自己的产物。编译器可用 CC 指定可执行文件路径。交叉编译产物应另行部署到匹配开发板，本入口默认主机运行。

## 练习

为每类帧对象添加申请、释放和在途计数。参考结论：生产速度大于消费速度造成的排队增长需要背压或丢弃策略，不能只靠 free 修补。

实际环境和输出见 verification.md。
