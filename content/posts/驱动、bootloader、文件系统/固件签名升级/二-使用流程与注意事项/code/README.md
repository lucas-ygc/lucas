# 签名升级离线检查工具

依赖 Python 3、OpenSSL 3.x。只读取显式指定的 .pkg 与可信 RSA-2048 公钥。

```sh
python3 check_package.py /path/to/release.pkg \
  --public-key /path/to/trusted-public.pem \
  --model BA4K --hardware HI3516CV610_00S
```

公钥须来自已核对的可信配置，不能无条件相信与未知包一同下载的公钥。
工具不接受私钥、不签名、不连接设备、不操作 NAND，也不改变发布状态。

检查范围：当前 TLUPG002/format=1 格式、768 字节头、RSA-2048 签名、身份、
保留字节、总长度、组件 SHA-256、FIT/SquashFS 基本魔数及容量。
不解析完整文件系统，不检查真实设备的内存、分区、启动槽和业务健康，不替代设备验签。
版本只需符合当前基本格式，不实施防降级。未来包格式或算法改变时需更新工具。

本次验证只使用临时随机教学密钥和合成测试包；无正式密钥、真实固件或设备信息进入下载包。
合成包用于测试格式检查，不是可启动镜像，不应刷入开发板。
