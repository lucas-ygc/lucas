# 哈希与签名离线实验

依赖：Python 3、OpenSSL 命令行工具。不需要 pip 包、SDK、板卡或正式密钥。

```sh
python3 demo.py
```

脚本在本目录的临时子目录中生成两对随机 RSA-2048 教学密钥，用小型文本模拟固件，
以 JSON 清单模拟受保护描述信息。正常退出或 Python 异常退出会清理临时目录；
断电或强杀可能留下 `.signature-demo-*`，其中只能是本实验随机产生的密钥，勿用于发布。

实验覆盖原始数据、错误公钥、镜像篡改、镜像与哈希同时篡改、替换签名公钥和清单字节变化。
不会读取正式项目密钥，不访问设备，不生成项目 .pkg，不修改发布版本计数。
下载包只包含源码、说明和验证记录，不包含任何 PEM 私钥或运行产物。

JSON 清单是教学载体，项目实际签名的是固定 512 字节二进制描述头，不是这里的 JSON。
