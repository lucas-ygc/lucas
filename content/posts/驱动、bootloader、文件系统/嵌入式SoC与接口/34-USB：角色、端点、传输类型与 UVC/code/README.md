# USB：角色、端点、传输类型与 UVC

使用 Python 3.10 或更高版本，无第三方依赖。解压后在本目录运行：

```bash
python3 main.py
```

示例使用构造参数演示机制和算术，不访问硬件。断言验证本文的参考结论；输出和实测环境见 verification.md。修改参数前先保留一份原始输出，并同时更新你推导的预期值和断言。

## 练习

只读查看设备枚举速率、接口和可用视频格式，记录实际协商结果。设备能枚举但无法开流时，检查格式、带宽、供电及驱动状态，而不是重复拔插作为唯一手段。

将压缩视频加入分析时，需要单独计入解码耗时；降低 USB 带宽不一定降低 CPU 或总延迟。
