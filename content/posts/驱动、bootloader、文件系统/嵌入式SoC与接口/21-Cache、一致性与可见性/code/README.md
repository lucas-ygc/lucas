# Cache、一致性与可见性

使用 Python 3.10 或更高版本，无第三方依赖。解压后在本目录运行：

```bash
python3 main.py
```

示例使用构造参数演示机制和算术，不访问硬件。断言验证本文的参考结论；输出和实测环境见 verification.md。修改参数前先保留一份原始输出，并同时更新你推导的预期值和断言。

## 练习

离线模型设置 CPU cache=新值、内存=旧值，观察设备读取结果；再模拟归还给 CPU 前的同步。模型不模拟真实 cache 指令，只揭示两份副本与所有权。

参考检查：提交后 CPU 不继续改输入，完成后设备不继续写已交给 CPU 的输出，缓冲再次提交前所有消费者都已释放。
