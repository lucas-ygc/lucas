# DSP：滤波、FFT、定点数与饱和

使用 Python 3.10 或更高版本，无第三方依赖。解压后在本目录运行：

```bash
python3 main.py
```

示例使用构造参数演示机制和算术，不访问硬件。断言验证本文的参考结论；输出和实测环境见 verification.md。修改参数前先保留一份原始输出，并同时更新你推导的预期值和断言。

## 练习

代码实现四点滑动平均和 Q15 饱和加法。检查 0.75+0.75 在饱和下接近 1，而在 16 位回绕下成为 -0.5。

把输入改为阶跃，观察滤波延迟；把采样率翻倍但保留系数，解释为什么对应的物理频率响应改变。实际 DSP 上还需测量每块处理周期和缓冲欠载，PC 上的 Python 时间不是 DSP 性能。
