# 寄存器、地址空间与 MMIO

使用 Python 3.10 或更高版本，无第三方依赖。解压后在本目录运行：

```bash
python3 main.py
```

示例使用构造参数演示机制和算术，不访问硬件。断言验证本文的参考结论；输出和实测环境见 verification.md。修改参数前先保留一份原始输出，并同时更新你推导的预期值和断言。

## 练习

构造状态值 0b101，两个置位位都按 W1C 规则工作。只清除 bit0 应写 0b001，结果保留 0b100；若将读值原样写回则两位都清除。

先给实际寄存器表标注访问语义，再设计修改函数。保留位应按手册规则处理，不能统一理解为“写零总安全”。
