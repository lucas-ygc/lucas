# 定时器、PWM、输入捕获与编码器

使用 Python 3.10 或更高版本，无第三方依赖。解压后在本目录运行：

```bash
python3 main.py
```

示例使用构造参数演示机制和算术，不访问硬件。断言验证本文的参考结论；输出和实测环境见 verification.md。修改参数前先保留一份原始输出，并同时更新你推导的预期值和断言。

## 练习

代码计算 72MHz、PSC=71、ARR=999 的 1kHz 周期，并处理 16 位捕获值从 65530 到 10 的回绕差 16。

硬件实验记录目标频率、实测频率、占空比和负载变化，再接已有[云台系列](/series/hi3516-pan-tilt/)。电机接口要经过对应驱动器，GPIO 不能直接承担电机电流。
