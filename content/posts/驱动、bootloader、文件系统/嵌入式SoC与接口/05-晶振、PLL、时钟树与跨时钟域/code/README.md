# 晶振、PLL、时钟树与跨时钟域

使用 Python 3.10 或更高版本，无第三方依赖。解压后在本目录运行：

```bash
python3 main.py
```

示例使用构造参数演示机制和算术，不访问硬件。断言验证本文的参考结论；输出和实测环境见 verification.md。修改参数前先保留一份原始输出，并同时更新你推导的预期值和断言。

## 练习

先计算 24MHz 参考、理想倍频 50、分频 4 时得到 300MHz，再查实际 PLL 允许的参数范围。代码只验证算术，不证明配置合法。

解释为何 8 位计数器从 0x7F 变为 0x80 时逐位同步可能观察到混合值。答案：多位同时变化且采样结果不保证一致，需要整体数据传递协议。
