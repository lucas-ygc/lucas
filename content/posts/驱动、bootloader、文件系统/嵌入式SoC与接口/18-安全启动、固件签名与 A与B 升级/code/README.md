# 安全启动、固件签名与 A/B 升级

使用 Python 3.10 或更高版本，无第三方依赖。解压后在本目录运行：

```bash
python3 main.py
```

示例使用构造参数演示机制和算术，不访问硬件。断言验证本文的参考结论；输出和实测环境见 verification.md。修改参数前先保留一份原始输出，并同时更新你推导的预期值和断言。

## 练习

画出下载、写入、校验、试启动、确认五个状态，在每个边界假设掉电并写出下次启动选择。不要使用“应该不会断电”作为状态转移条件。

签名实验与交付流程接[固件签名升级系列](/series/firmware-signing/)。本课代码只模拟槽状态机，不是密码实现，也不写实际启动分区。
