# CSI-2：数据类型、虚拟通道与带宽预算

使用 Python 3.10 或更高版本，无第三方依赖。解压后在本目录运行：

```bash
python3 main.py
```

示例使用构造参数演示机制和算术，不访问硬件。断言验证本文的参考结论；输出和实测环境见 verification.md。修改参数前先保留一份原始输出，并同时更新你推导的预期值和断言。

## 练习

代码计算有效负载和一个明确标注为假设的 20% 预算余量。该余量不是 MIPI 标准规定，也不替代实际 mode 参数。

把位深从 10 改成 12，帧率从 30 改为 60，观察预算如何增长；然后分别计算接收后 16 位容器的 DDR 写入量，解释为什么两个速率不同。
