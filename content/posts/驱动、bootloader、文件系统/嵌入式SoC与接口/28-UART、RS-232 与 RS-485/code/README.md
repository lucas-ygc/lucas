# UART、RS-232 与 RS-485

使用 Python 3.10 或更高版本，无第三方依赖。解压后在本目录运行：

```bash
python3 main.py
```

示例使用构造参数演示机制和算术，不访问硬件。断言验证本文的参考结论；输出和实测环境见 verification.md。修改参数前先保留一份原始输出，并同时更新你推导的预期值和断言。

## 练习

计算发送 256 字节、115200、8N1 的理想线时长约 22.22ms。对照应用写调用耗时与引脚实际波形，解释为何二者不同。

构造尾字节丢失故障，优先比较 DE 下降与最后停止位，而不是只在上层不断加重试。测量前核对收发器侧与逻辑侧，避免把高电压线路直接接入普通分析仪。
