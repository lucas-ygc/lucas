# 显示链路：DSI、RGB、LVDS 与 HDMI

使用 Python 3.10 或更高版本，无第三方依赖。解压后在本目录运行：

```bash
python3 main.py
```

示例使用构造参数演示机制和算术，不访问硬件。断言验证本文的参考结论；输出和实测环境见 verification.md。修改参数前先保留一份原始输出，并同时更新你推导的预期值和断言。

## 练习

构造水平总长 2200、垂直总高 1125、60Hz，像素时钟为 148.5MHz。该例不授权给任意 1080p 面板使用，必须匹配具体 mode。

黑屏排查分成供电/背光、复位与初始化、链路时钟、有效时序、缓冲内容。用可控纯色或棋盘测试区分像素格式与业务绘制问题。
