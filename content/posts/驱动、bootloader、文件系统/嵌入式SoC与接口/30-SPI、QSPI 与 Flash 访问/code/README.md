# SPI、QSPI 与 Flash 访问

使用 Python 3.10 或更高版本，无第三方依赖。解压后在本目录运行：

```bash
python3 main.py
```

示例使用构造参数演示机制和算术，不访问硬件。断言验证本文的参考结论；输出和实测环境见 verification.md。修改参数前先保留一份原始输出，并同时更新你推导的预期值和断言。

## 练习

手算 8 位命令、24 位地址、8 个 dummy 时钟和 256 字节数据，在单线 SDR 与仅数据四线 SDR 下分别占多少时钟。答案为 2088 与 552；不包含片选间隔。

用逻辑分析仪比较实际片选和边沿，先降低到器件支持的保守模式建立参考，再按手册调整。不要在未知 Flash 内容上试写命令验证接口。
