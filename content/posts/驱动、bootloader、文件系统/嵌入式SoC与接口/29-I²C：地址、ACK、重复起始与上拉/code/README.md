# I²C：地址、ACK、重复起始与上拉

使用 Python 3.10 或更高版本，无第三方依赖。解压后在本目录运行：

```bash
python3 main.py
```

示例使用构造参数演示机制和算术，不访问硬件。断言验证本文的参考结论；输出和实测环境见 verification.md。修改参数前先保留一份原始输出，并同时更新你推导的预期值和断言。

## 练习

代码按构造地址 0x36 得到写字节 0x6C、读字节 0x6D，并估算 RC 上升时间。这个地址只用于教学。

纸上解码 START、地址、ACK、寄存器索引、重复 START、数据、NACK、STOP。真实板上先使用已知合法读取，再分析波形；不把盲目全地址扫描作为无副作用操作。
