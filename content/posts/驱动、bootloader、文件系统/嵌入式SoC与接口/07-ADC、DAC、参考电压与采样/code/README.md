# ADC、DAC、参考电压与采样

使用 Python 3.10 或更高版本，无第三方依赖。解压后在本目录运行：

```bash
python3 main.py
```

示例使用构造参数演示机制和算术，不访问硬件。断言验证本文的参考结论；输出和实测环境见 verification.md。修改参数前先保留一份原始输出，并同时更新你推导的预期值和断言。

## 练习

配套计算得到 3.3V、12 位的理想间隔约 0.806mV，并比较 800Hz 与其混叠频率。所有输入是构造值。

硬件练习用已知低压直流源记录均值、极值和参考电压，再改变采样时间或源阻抗。先确保输入在允许范围内，测量接线及保护属于实验条件，不能由量化公式代替。
