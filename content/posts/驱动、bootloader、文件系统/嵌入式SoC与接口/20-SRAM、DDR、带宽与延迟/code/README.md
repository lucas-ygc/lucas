# SRAM、DDR、带宽与延迟

使用 Python 3.10 或更高版本，无第三方依赖。解压后在本目录运行：

```bash
python3 main.py
```

示例使用构造参数演示机制和算术，不访问硬件。断言验证本文的参考结论；输出和实测环境见 verification.md。修改参数前先保留一份原始输出，并同时更新你推导的预期值和断言。

## 练习

代码以 NV12 和 RGB888 为例计算有效帧大小，以及假设每秒 30 帧、多次读写时的流量。明确结果使用十进制 MB/s。

板端给每段画读写箭头，结合平台计数器或测量验证。对齐、缓存与 QoS 未建模的算术结果只能用作预算，不是实际性能保证。
