# NPU：张量计算、片上存储与 TOPS

使用 Python 3.10 或更高版本，无第三方依赖。解压后在本目录运行：

```bash
python3 main.py
```

示例使用构造参数演示机制和算术，不访问硬件。断言验证本文的参考结论；输出和实测环境见 verification.md。修改参数前先保留一份原始输出，并同时更新你推导的预期值和断言。

## 练习

构造 1 GOP 工作量、100 MB 搬运、1 TOPS 可用计算率和 5 GB/s 有效带宽。计算下界为 1ms，搬运下界为 20ms；仅提高计算峰值无法消除搬运限制。

单位全部使用十进制，并保持 OP 计数口径一致。代码输出的是假设条件下的下界，不是芯片跑分。
