# Patch、token 与 ViT 前向计算

在本目录运行，或将网页下载包解压后运行。输入均在脚本内构造，不依赖其他文章，不联网下载。

建议使用 Python 3.11+ 虚拟环境，安装依赖：

```bash
python3 -m pip install -r requirements.txt
```

```bash
python3 main.py
```

## 观察结果

输入 [2,3,32,32] 被划为 16 个 patch，输出 [2,2]；随机权重只验证结构。
