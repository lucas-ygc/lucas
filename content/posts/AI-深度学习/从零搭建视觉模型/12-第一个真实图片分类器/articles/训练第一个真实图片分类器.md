## 从条纹走向真实图片

条纹任务帮助我们理解训练循环，但它的规则太整齐。真实图片包含背景、姿态、光照和遮挡，本课用 CIFAR-10 的飞机与汽车子集建立一个可重复的二分类基线。我们仍然只判断整图类别，不输出目标框。

CIFAR-10 图片尺寸很小，适合教学，却不能证明模型能处理真实摄像头拍摄的图片。任务限定为两类还意味着：遇到猫、空背景或模糊帧时，模型仍可能强行给出其中一类。后续产品必须重新设计数据与拒绝机制。

## 数据约定先固定

原数据的飞机和汽车编号分别为 0、1，本课显式筛选并保留这一顺序。只从官方训练部分划出验证集，官方测试部分暂不读取。每类先取固定随机排序后的 1000 张训练、200 张验证，缩短第一轮实验时间。

这是教学子集规模，不是正式性能评测协议。不同划分、更多数据或不同随机种子可能改变结果。数据接口与下载行为以 [Torchvision CIFAR10 文档](https://docs.pytorch.org/vision/stable/generated/torchvision.datasets.CIFAR10.html)为准；实际使用还需阅读数据集来源的使用说明。

本课采用 RGB、32×32、`ToTensor()` 转换到浮点 0～1，不再额外标准化。训练和验证都使用同一确定性输入处理，先建立基线。后面添加随机增强时才改变训练处理。

## 一个可以读完的完整训练入口

下面脚本依赖匹配版本的 PyTorch 与 Torchvision。配套 `code/train.py` 已将此流程整理为带参数的入口，可直接执行；运行目录的 `data/` 保存数据，`runs/` 保存产物，它们都不应自动发布。

默认 `download=False`，要求本地已有 CIFAR-10。配套脚本首次准备数据时显式传入 `--download`，这会访问数据源并下载。这里没有把下载或真实训练写成已经完成的事实。

```python
from pathlib import Path
import copy
import random
import torch
from torch import nn
from torch.utils.data import DataLoader, Subset
from torchvision import datasets, transforms

torch.manual_seed(7)
torch.set_num_threads(2)

class TinyCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 8, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(8, 16, 3, padding=1), nn.ReLU(),
            nn.AdaptiveAvgPool2d(1),
        )
        self.head = nn.Linear(16, 2)

    def forward(self, x):
        return self.head(self.features(x).flatten(1))

raw = datasets.CIFAR10('data', train=True, download=False,
                       transform=transforms.ToTensor())
train_ids, val_ids = [], []
for label in (0, 1):
    ids = [i for i, y in enumerate(raw.targets) if y == label]
    random.Random(7 + label).shuffle(ids)
    train_ids.extend(ids[:1000])
    val_ids.extend(ids[1000:1200])
assert not (set(train_ids) & set(val_ids))
train_loader = DataLoader(Subset(raw, train_ids), batch_size=32,
                          shuffle=True, num_workers=0)
val_loader = DataLoader(Subset(raw, val_ids), batch_size=64,
                        shuffle=False, num_workers=0)
model = TinyCNN()
loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3)

@torch.no_grad()
def evaluate():
    model.eval()
    total_loss = correct = count = 0
    for images, labels in val_loader:
        logits = model(images)
        total_loss += loss_fn(logits, labels).item() * len(labels)
        correct += (logits.argmax(1) == labels).sum().item()
        count += len(labels)
    return total_loss / count, correct / count

best_loss, best_state, best_epoch = float('inf'), None, 0
for epoch in range(1, 6):
    model.train()
    total_loss = count = 0
    for images, labels in train_loader:
        optimizer.zero_grad()
        logits = model(images)
        loss = loss_fn(logits, labels)
        loss.backward()
        optimizer.step()
        total_loss += loss.item() * len(labels)
        count += len(labels)
    val_loss, val_acc = evaluate()
    print(epoch, total_loss / count, val_loss, val_acc)
    if val_loss < best_loss:
        best_loss = val_loss
        best_state = copy.deepcopy(model.state_dict())
        best_epoch = epoch

Path('runs').mkdir(exist_ok=True)
torch.save({
    'model': best_state, 'epoch': best_epoch,
    'classes': ['airplane', 'automobile'],
    'input': {'size': [32, 32], 'color': 'RGB', 'scale': '0..1'},
    'train_ids': train_ids, 'val_ids': val_ids,
}, 'runs/best.pt')
```

## 逐段理解这份脚本

前两个卷积层处理局部空间信息，池化减少尺寸；自适应平均池化将每个通道归约为一个值，输出 16 个特征；线性层产生两个类别的 logits。这里沿用 CNN 概念，但不依赖其他文章的辅助模块。

`evaluate()` 用固定参数统计验证结果，既调用 `eval()` 又关闭梯度。每轮训练开始重新 `train()`。如果以后加入 Dropout 或 BatchNorm，这些模式切换就会影响计算行为。

保存最佳参数时用了深复制。若只是把 `state_dict()` 赋给变量后继续训练，其中张量可能仍指向更新中的状态，最终保存的就不一定是当时最佳模型。

## 第一次运行该观察什么

先确认批次形状是 `[N,3,32,32]`、标签只有 0 和 1、输出是 `[N,2]`。然后观察训练损失是否有下降趋势，验证集是否明显优于简单基线。二分类均衡子集的固定单类预测准确率为 50%，但随机初始化某一次的结果不必恰好 50%。

如果训练损失完全不动，先缩小到少量样本排查训练链路；如果训练很好、验证很差，检查划分、样本分布与过拟合。不要靠增加网络复杂度掩盖基础错误。

本草稿没有给出虚构的“五轮达到多少准确率”。后续实测应记录依赖版本、划分、实际耗时、训练曲线和失败样本，并在方案确定后才使用官方测试部分。

## 练习

2. 为什么不能用测试集挑选最佳 epoch？
3. 为什么最佳模型以验证损失选择，却仍打印验证准确率？

<details class="exercise-answer">
<summary>参考答案</summary>

比较训练和验证曲线、错误类别与运行成本，不能只看最后一轮训练准确率。测试集参与选 epoch 会变成调参依据，使最终报告偏乐观。损失体现分布与置信程度，准确率体现离散分类结果，两者可能变化不同；选择准则应提前固定。

</details>
