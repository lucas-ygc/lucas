## B. 搭网络的层

| 写法 | 作用 | 出处 |
| --- | --- | --- |
| `class X(nn.Module)` + `super().__init__()` | 网络基类；初始化后框架才能登记子模块和参数 | [05](/posts/vision-mlp-basics.html) [06](/posts/vision-tiny-cnn.html) |
| `def forward(self, x)` / `model(x)` | 声明数据流向；用调用入口执行，不要直接调 `forward` | [05](/posts/vision-mlp-basics.html) [06](/posts/vision-tiny-cnn.html) |
| `nn.Sequential(a, b, c)` | 按顺序依次执行若干层，适合线性堆叠 | [12](/posts/vision-first-real-classifier.html) [16](/posts/vision-resnet.html) [22](/posts/vision-onnx-export.html) |
| `nn.Conv2d(ci, co, k, stride, padding)` | 卷积：`co` 套核，每套跨全部 `ci` 输入通道，各出一张特征图；参数 `co×ci×k×k+co` | [06](/posts/vision-tiny-cnn.html) [08](/posts/vision-training-basics.html) [16](/posts/vision-resnet.html) |
| `nn.MaxPool2d(k, s)` | 每个通道独立在窗口内取最大值；缩小空间，无参数 | [06](/posts/vision-tiny-cnn.html) [12](/posts/vision-first-real-classifier.html) |
| `nn.AdaptiveAvgPool2d((1, 1))` | 任意高宽都平均池化成 1×1，解除 `Linear` 对尺寸的写死 | [12](/posts/vision-first-real-classifier.html) [18](/posts/vision-efficient-models.html) [22](/posts/vision-onnx-export.html) |
| `nn.BatchNorm2d(c)` | 逐通道规范化；`train` 用本批统计并更新运行值，`eval` 用运行值 | [16](/posts/vision-resnet.html) |
| `nn.ReLU()` | 逐元素把负数归 0，提供非线性，无参数 | [05](/posts/vision-mlp-basics.html) [06](/posts/vision-tiny-cnn.html) |
| `nn.Flatten(start_dim=1)` | 保留 N 轴，把后面各轴排成一条；数不变，只是排队 | [05](/posts/vision-mlp-basics.html) [06](/posts/vision-tiny-cnn.html) |
| `nn.Linear(入, 出)` | 全连接：每个输出是一条输入的加权和加偏置；参数 `入×出+出` | [05](/posts/vision-mlp-basics.html) [06](/posts/vision-tiny-cnn.html) [22](/posts/vision-onnx-export.html) |
| `nn.Parameter(t)` | 把张量声明为模块的可训练参数 | [21](/posts/vision-attention-vit.html) |
| `nn.TransformerEncoderLayer(d, nhead)` | 现成的自注意力加前馈块，用于与手写版本对照 | [21](/posts/vision-attention-vit.html) |
| `F.relu / F.max_pool2d` | 层对应的函数形式，方便在 `forward` 里直接调用 | [05](/posts/vision-mlp-basics.html) [20](/posts/vision-segmentation-unet.html) |
| `F.interpolate(x, ...)` | 上采样，把小掩码或特征图放大回目标尺寸 | [20](/posts/vision-segmentation-unet.html) |
| `F.cross_entropy(logits, 标签)` | 一步算出分类损失，适合循环内临时调用 | [10](/posts/vision-loss-optimizers.html) |
| `F.binary_cross_entropy_with_logits` | 逐像素二分类损失，用于分割掩码 | [20](/posts/vision-segmentation-unet.html) |

## C. 训练循环

| 写法 | 作用 | 出处 |
| --- | --- | --- |
| `nn.CrossEntropyLoss()` | 把 logits 与整数标签算成一个标量损失 | [08](/posts/vision-training-basics.html) [12](/posts/vision-first-real-classifier.html) |
| `torch.optim.SGD(参数, lr=)` | 沿梯度反方向按固定步长更新 | [08](/posts/vision-training-basics.html) [10](/posts/vision-loss-optimizers.html) |
| `torch.optim.SGD(..., momentum=)` | 给更新加惯性，冲过小坑 | [10](/posts/vision-loss-optimizers.html) |
| `torch.optim.AdamW(参数, lr=)` | 逐参数自适应步长加权重衰减； lr 通常比 SGD 小一个量级 | [10](/posts/vision-loss-optimizers.html) [17](/posts/vision-transfer-learning.html) [20](/posts/vision-segmentation-unet.html) |
| `loss.backward()` | 反向传播：为每个参数计算梯度并**累加** | [08](/posts/vision-training-basics.html) [12](/posts/vision-first-real-classifier.html) |
| `opt.zero_grad()` | 清掉上一轮累加的梯度；PyTorch 不自动清，漏写会污染更新 | [08](/posts/vision-training-basics.html) [12](/posts/vision-first-real-classifier.html) |
| `opt.step()` | 按当前梯度真正修改参数数值 | [08](/posts/vision-training-basics.html) [12](/posts/vision-first-real-classifier.html) |
| `model.train()` / `model.eval()` | 切换行为模式（影响 BatchNorm、Dropout），不改变是否记录梯度 | [08](/posts/vision-training-basics.html) [13](/posts/vision-generalization.html) [16](/posts/vision-resnet.html) |
| `with torch.no_grad():` | 块内不记录梯度；推理、验证、导出检查都用它 | [06](/posts/vision-tiny-cnn.html) [12](/posts/vision-first-real-classifier.html) [15](/posts/vision-checkpoint-inference.html) [22](/posts/vision-onnx-export.html) |
| `model.parameters()` | 遍历全部可训练张量；配合 `numel()` 数参数 | [06](/posts/vision-tiny-cnn.html) [12](/posts/vision-first-real-classifier.html) |
