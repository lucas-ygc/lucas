# 小型 U-Net 的一次训练步

在本目录运行，或将网页下载包解压后运行。输入均在脚本内构造，不依赖其他文章，不联网下载。

建议使用 Python 3.11+ 虚拟环境，安装依赖：

```bash
python3 -m pip install -r requirements.txt
```

```bash
python3 main.py
```
