## 一个准确率数字隐藏了什么

假设某数据中 95% 都是汽车，程序永远回答汽车就能达到 95% 准确率，却完全不会识别飞机。指标必须结合类别分布与任务代价解释。

本课把汽车视为正类、飞机视为负类。正负只是一种统计约定，不表示好坏。换了正类，精确率和召回率的含义也跟着变，因此报告时必须写清楚。

## 从四种结果建立混淆矩阵

| 真实与预测 | 预测汽车 | 预测飞机 |
| --- | --- | --- |
| 真实汽车 | TP：正确找出汽车 | FN：漏掉汽车 |
| 真实飞机 | FP：误报汽车 | TN：正确排除汽车 |

准确率为 `(TP+TN)/总数`，精确率为 `TP/(TP+FP)`，召回率为 `TP/(TP+FN)`。精确率问“报出来的有多少是真的”，召回率问“真实存在的找出了多少”。

下面是一组固定标签的独立手算检查：

```python
truth = [1, 1, 1, 1, 0, 0]
pred =  [1, 1, 0, 0, 1, 0]
tp = sum(y == 1 and p == 1 for y, p in zip(truth, pred))
fp = sum(y == 0 and p == 1 for y, p in zip(truth, pred))
fn = sum(y == 1 and p == 0 for y, p in zip(truth, pred))
tn = sum(y == 0 and p == 0 for y, p in zip(truth, pred))
print(tp, fp, fn, tn)
print('precision:', tp / (tp + fp))
print('recall:', tp / (tp + fn))
assert (tp, fp, fn, tn) == (2, 1, 2, 1)
```

本例精确率为 2/3、召回率为 1/2、准确率为 1/2。如果分母为零，指标并没有天然合理的数值，应注明采用未定义、零值或工具规定的处理方式。

## 阈值会改变错误的分布

二分类按汽车概率超过阈值报警时，降低阈值通常会接收更多样本，可能减少漏报、增加误报。这个方向不是对任意一小批数据都保证严格变化，但能帮助理解取舍。

阈值应使用验证集和业务代价确定，随后冻结，再在测试集上测试。不能先在测试集尝试几十个阈值，再把最好的结果当作独立验证。

多类别也要看每类指标。宏平均给各类别同等权重，按样本量加权的平均则更受大类影响。比较两个报告前先核对类别集合、平均方式和样本来源。

## 先看错误图，再改模型

为错误样本保存文件 ID、真实标签、预测标签、分数和来源组；按小目标、遮挡、逆光、背景相似、标签错误等条件归类。几张高分错误图往往能暴露 RGB 顺序、裁剪和标签映射问题。

如果错误主要发生在某个拍摄来源，先检查分布变化；如果模型总是混淆两类的细节，检查分辨率和标注定义；如果所有类别突然反转，先检查类别表。直接换更深网络可能把错误隐藏得更难定位。

错误分析需要避免反复利用测试集做开发。开发阶段用训练与验证错误建立假设，最终测试用于检验已冻结方案；若已经依据测试错误做了修改，需要新的独立评估来源或明确承认测试被用于开发。

## 测试报告应能回答的四个问题

用了哪些样本，采用哪份模型和预处理，按什么决策规则计算，结果在哪些条件下失效。还应记录样本数，避免把 10 张测试图上的 100% 与几千张独立图片的成绩相提并论。

相关样本数量很多也不等于独立证据很多。一段视频的 10000 个相邻帧不能简单当作 10000 次独立试验；泛化范围取决于来源覆盖和相关性。

本草稿的固定数组可以验证指标计算，但没有真实模型测试成绩。发布前应导出验证错误清单，在配置冻结后执行独立测试，并保存可追溯报告。
