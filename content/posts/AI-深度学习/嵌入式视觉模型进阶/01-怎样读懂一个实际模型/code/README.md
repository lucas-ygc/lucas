# 怎样读懂一个实际模型

从输入契约、层级结构和输出语义出发，检查模型形状、参数与运行模式。

## 快速运行

使用 Python 3.11+，在本目录或下载包解压目录执行。建议使用独立虚拟环境。

```bash
python3 -m pip install -r requirements.txt
python3 main.py
```

默认实验使用代码内构造输入或包内样例，不自动下载模型和数据。每篇辅助文件都在本包内，无跨文章目录依赖。
